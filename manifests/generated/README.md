# Bootstrap-Generated GitOps Artifacts

This directory is the artifact **registry**. The actual patch files are
generated by the Day-0 CLI into each consuming kustomization's own
`generated/` subdirectory (required by kustomize `patches:` path
restrictions — files must reside within the kustomization root).

## Source of Truth

The file `artifacts.yaml` is the machine-parseable registry of required
artifacts, keyed by repo-root-relative paths. The CLI reads this file
during `BootstrapInfisicalAPI` to determine what to generate and where
to write it.

## Rules

- **Do not commit generated files.** Only `artifacts.yaml` and `README.md`
  are committed in this directory. Generated files in each consumer's
  `generated/` subdirectory are produced by `hub bootstrap`.
- **Do not store secrets.** Passwords, tokens, private keys, and certificates
  are forbidden here (see ADR-003, ADR-035).
- **Must be deterministic.** Identical inputs produce identical outputs.

## Lifecycle

1. **Generation** — CLI writes patch files during `BootstrapInfisicalAPI`
   into each consumer's `generated/` subdirectory (paths defined in
   `artifacts.yaml`).
2. **Commit + Push** — Operator or CI commits and pushes generated files.
3. **Reconciliation** — ArgoCD syncs via kustomize `patches:`.
4. **Rotation** — Regenerate the artifact and commit the change.
