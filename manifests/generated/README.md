# Bootstrap-Generated GitOps Artifacts

This directory contains manifests generated by the Day-0 CLI during bootstrap
(reference: ADR-045).

## Rules

- **Do not edit manually.** These files are written by `hub bootstrap`.
- **Do not commit placeholders.** Missing artifacts fail bootstrap fast.
- **Do not store secrets.** Passwords, tokens, private keys, and certificates
  are forbidden here (see ADR-003, ADR-035).
- **Must be deterministic.** Identical inputs produce identical outputs.
- **Must be committed and pushed** before the platform can progress beyond
  bootstrap.

## Lifecycle

1. **Generation** (bootstrap completion) — CLI writes the artifact during
   the appropriate bootstrap phase (ADR-042).
2. **Commit + Push** (platform readiness) — Operator or CI commits and
   pushes generated artifacts before platform readiness is achieved.
3. **Reconciliation** — ArgoCD syncs the artifact via `patches:` in the
   consuming kustomization.
4. **Rotation** — Regenerate the artifact and commit the change.
