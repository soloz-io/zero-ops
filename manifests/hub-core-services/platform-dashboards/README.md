`dashboard-*.yaml` here are generated by `scripts/observability/mixin/generate.sh`
(ADR-078 add.2 §2, add.3 §4). Do not edit them: change
`scripts/observability/mixin/platform.libsonnet` and regenerate. CI regenerates
on every change and fails a branch whose committed output differs.

top-level files only.
