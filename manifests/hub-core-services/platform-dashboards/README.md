`dashboard-*.yaml` here are generated by `scripts/observability/mixin/generate.sh`
(ADR-078 add.2 §2, add.5 §6). Do not edit them: change
`scripts/observability/mixin/platform.libsonnet` and regenerate. CI regenerates
on every change and fails a branch whose committed output differs.

The directory is flat on purpose: the bundle packages a directory component's
top-level files only.

`grafana.yaml` is the hub's Grafana (ADR-078 add.5 §6): the in-cluster instance,
its database credential, the hub's datasources (through VMAuth) and its route.
