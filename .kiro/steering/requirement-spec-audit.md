# requirements.md
**Purpose**: Defines WHAT the system must do

- Written in structured EARS patterns (WHEN/WHILE/IF/THEN)
- Contains user stories and acceptance criteria
- Focuses on business needs and functional requirements
- Testable, measurable statements
- No implementation details
- Example: "WHEN a user submits a form, THE System SHALL validate all required fields"
